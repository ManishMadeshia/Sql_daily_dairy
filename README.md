# SQL Practice Journey 🚀

This repository contains my daily SQL practice as part of my journey to become a Data Engineer.

I am practicing SQL every day by covering topics from basic queries to advanced concepts. For each topic, I solve **5–10 practice questions** to strengthen my understanding and improve problem-solving skills.
